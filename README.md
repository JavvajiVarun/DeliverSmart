# DeliverSmart

DeliverSmart is an Android application designed to help delivery drivers quickly evaluate delivery offers.

## Features

- Captures delivery offer information from the screen
- Uses OCR to extract offer details
- Calculates estimated earnings and delivery metrics
- Evaluates delivery offers based on payout and distance
- Categorizes offers as Good, Average, or Bad
- Displays useful information through an Android overlay

## Tech Stack

- Kotlin
- Android Studio
- Google ML Kit Text Recognition
- Android Accessibility / Screen Capture APIs
